# Dans Set Home Commands

| Command | Description | Permission |
|---------|-------------|------------|
| `/sethome` | Set your home to your current location. | `dsh.sethome` |
| `/home` | Teleport to your home location. | `dsh.home` |
| `/home <player>` | Teleport to another player's home location. | `dsh.home.others` |
| `/dsh help` | View a list of commands. | `dsh.help` |
| `/dsh forcesave` | Force save player data (console/admin). | `dsh.forcesave` |
| `/dsh forceload` | Force load player data (console/admin). | `dsh.forceload` |
